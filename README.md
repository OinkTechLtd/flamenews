# FlameNews (THEME)

Automated article aggregator using Python for crawling and Node.js for delivery.

## Tech Stack
- **Backend:** Node.js, Express
- **Crawler:** Python (BeautifulSoup, Requests)
- **Frontend:** Modern HTML/CSS with mobile-first design
- **Automation:** GitHub Actions

## Setup
1. Install node dependencies: `npm install express`
2. Install python dependencies: `pip install beautifulsoup4 requests`
3. Run crawler manually: `python crawler.py`
4. Start server: `node server.js`

Articles are served internally without redirecting to external sites.
